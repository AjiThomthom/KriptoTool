Tentang KriptoTool

Aplikasi berbasis web untuk enkripsi & dekripsi pesan atau teks menggunakan algoritma kriptografi klasik. Dibangun sebagai tugas praktikum mata kuliah Kriptografi.

Seluruh proses dijalankan client-side menggunakan Python. Sehingga data Anda tidak pernah meninggalkan browser menjadikannya aman dan cepat.

Open Source

Seluruh kode sumber KriptoTool terbuka untuk umum. Kamu bisa mempelajari, memodifikasi, atau berkontribusi untuk pengembangan lebih lanjut.
